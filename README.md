## Теория о методах API в Битрикс24.

Строка telephony.externalCall.register — это конкретный метод API (команда, которую выполняет код).
В архитектуре Битрикс24 эта строка делится на три строгих раздела, от общего к частному (как адрес на конверте: Страна ➔ Город ➔ Улица)
Вот как правильно называется каждый раздел:

 telephony  .  externalCall  .  register
 ────┬────     ───────┬─────    ─────┬────
     │                │              └─► 3. Метод (Method) / Действие
     │                └────────────────► 2. Сущность (Entity) / Объект
     └─────────────────────────────────► 1. Пространство имен (Namespace) / Модуль (скоуп (Scope)=объем)

1. telephony — Пространство имен (Namespace) или Скоуп (Scope)
Это самый верхний уровень — модуль системы. Он указывает, к какой глобальной части Битрикс24 относится команда.В коде разработчики называют это Namespace (пространство имен), чтобы команды из разных модулей не перепутались.В настройках прав этот же раздел совпадает с названием Скоупа (Scope).
2. externalCall — Сущность (Entity) или Объект (Object)
Это конкретный объект или подмодуль внутри телефонии, с которым мы хотим поработать. В данном случае мы работаем не со звонками внутри Битрикса вообще, а именно с внешними звонками (через стороннюю АТС).
3. register — Метод (Method) или Действие (Action)
Это конкретное действие, которое нужно совершить с выбранной сущностью. 
# Это всегда глагол или команда: register (зарегистрировать), finish (завершить), search (найти). В коде это финальная функция, которая запускает процесс.

Пример в понятиях ООП.

telephony  .  externalCall  .  register
────┬────     ───────┬──────   ─────┬──
    │                │              └─► 3. Метод класса (Method)
    │                └────────────────► 2. Свойство-объект / Экземпляр класса (Property/Instance)
    └─────────────────────────────────► 1. Главный класс / Модуль (Class / Namespace)

* telephony — Это Экземпляр класса (или Namespace)
В ООП это главный объект, который отвечает за весь модуль. Он объединяет в себе все возможности телефонии. Внутри него «живут» другие более мелкие объекты.
* externalCall — Это Свойство-Объект (Property или Компонент)
Это объект внутри объекта (паттерн «Композиция»). Класс TelephonyModule содержит в себе свойство externalCall, которое является экземпляром другого класса — например, ExternalCallManager. Он умеет управлять только внешними звонками.
* register — Это Метод класса (Method)
В ООП функция, написанная внутри класса, называется методом. Это конкретная программная функция (глагол), которая принимает параметры (например, номер телефона, ID сотрудника) и выполняет работу.
